# 03 · Avatares, problemas y ángulos

Sacado de los anuncios de TWP y MBE (archivo 02) y de sus reseñas (Loox de TWP, ~14.000 reseñas; Loox de MBE). Solo se listan avatares, problemas y ángulos que estas marcas usan.

## Las dos compras
TWP le habla a dos personas a la vez, y casi siempre en el mismo anuncio (el copy le habla a una y el título a la otra):
1. **La que regala** (la mayoría): busca un regalo para alguien que lee. Títulos: "el regalo perfecto para quien lee", "para el lector que tiene todo".
2. **La que lee y se lo compra para sí**: quiere su biblioteca con su sello. Copys: "me obsesiona", "dejá tu marca", "libros prestados".

**Segmentos que aparecen solo en reseñas** (TWP no les hace anuncios propios; sirven para contenido orgánico y reseñas, no para campañas aparte): docentes con biblioteca de aula, bibliotecarias, bibliotecas libres de barrio, autores que sellan sus propios libros, clubes de lectura.

**Embosador con logo (empresas):** TWP lo vende, pero no se encontraron anuncios. Por la regla, no se hacen campañas para empresas.

## Objeciones que responden (y dónde)
| Objeción | Respuesta de TWP/MBE | Dónde aparece |
|---|---|---|
| ¿Daña el libro? | Cuida las hojas; presión suave | Bullets, banda de beneficios, preguntas |
| ¿Es difícil de usar? | Una presión y listo; se usa apenas se abre | Video V2, pre-lander "10 razones" |
| ¿Dura? | [MATERIAL], para toda la vida | Bullets, video de la plantilla 2 |
| ¿En qué papeles sirve? | Libros, sobres, stickers; no cartón | Preguntas frecuentes |
| ¿Y si no le gusta? | 90 días de devolución | Microcopy bajo el botón |
| ¿Baja el valor del libro? | MBE lo responde con honestidad: puede afectar la reventa | Preguntas de MBE |
| ¿Llega a tiempo para el regalo? | Plazos de producción + envío; seguimiento | Políticas, preguntas |

Quejas reales en reseñas que el contenido debe anticipar: envíos lentos o sin información, "costó un poco armarlo", "practicá primero para saber cuánta presión hacer". En MBE (Trustpilot), pedidos que no llegaron.

## Cruce rápido para armar campañas
- **Prospección (regalo):** ángulo "regalo que emociona" + "regalo para quien tiene todo" → A1–A4 → plantillas 1 (V1), 11, 9 (con historias reales) → destino: ficha o pre-lander "5 razones".
- **Prospección (para sí):** ángulo "obsesión" + "legado" → A5 → plantillas 2 y 1 (V2) → destino: ficha o colecciones.
- **Prospección (problema):** ángulo "libros prestados" → A6 → plantillas 6 y 7 → destino: ficha.
- **Nicho / estacional:** "papelería de boutique" → A7 → plantillas 3 y 8 → destino: iniciales o bodas.
- **Remarketing:** catálogo dinámico (plantilla 4) + muro de reseñas.
